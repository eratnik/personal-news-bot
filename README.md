# Eratnik Home Assistant Apps

Приложения Home Assistant для личного использования.

- **Vino News Bot** — публикации сайтов, RSS и групп ВКонтакте в Telegram.
- **Telegram Transcriber** — локальная расшифровка голосовых через установленный Whisper.

## Установка

1. В Home Assistant откройте **Settings → Apps → App Store**.
2. Откройте меню ⋮ → **Repositories** и добавьте:
   `https://github.com/eratnik/personal-news-bot`
3. Выберите **Vino News Bot** или **Telegram Transcriber**, установите и настройте приложение.

Токен Telegram и идентификаторы чатов задаются только в настройках приложения Home Assistant и не хранятся в этом репозитории.

## Обновление

Когда выйдет новая версия, Home Assistant покажет обновление на странице приложения. Установите его обычной кнопкой **Update**.

## Перенос Telegram Transcriber

HA считает приложения из разных репозиториев отдельными установками.
Скопируйте конфигурацию старого Transcriber в безопасное локальное место.
Остановите старый Transcriber и отключите его запуск при загрузке.
Установите Telegram Transcriber из этого репозитория, перенесите конфигурацию и запустите.
Whisper используется тот же. Отправьте короткую запись и проверьте ответ.
После успешной проверки удалите старую установку и репозиторий ha-telegram-transcriber из магазина HA.
Одновременно должен работать только один обработчик одного Telegram-бота.
Новая установка имеет отдельный offset, поэтому при первом запуске возможна обработка накопившихся сообщений.
