# Personal News Bot

Персональное дополнение Home Assistant для доставки новых публикаций с RSS-лент и сайтов в Telegram.

## Установка

1. В Home Assistant откройте **Settings → Apps → App Store**.
2. Откройте меню ⋮ → **Repositories** и добавьте:
   `https://github.com/eratnik/personal-news-bot`
3. Найдите **Vino News Bot**, установите и настройте его.

Токен Telegram и идентификаторы чатов задаются только в настройках приложения Home Assistant и не хранятся в этом репозитории.

## Обновление

Когда выйдет новая версия, Home Assistant покажет обновление на странице приложения. Установите его обычной кнопкой **Update**.
