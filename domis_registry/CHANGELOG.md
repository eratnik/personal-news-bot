# История изменений

## 0.3.0

- В панели приложения можно сохранять и редактировать ключевые слова и коды ТН ВЭД.
- Добавлены стартовые запросы для бытовой техники и выбор сохранённого фильтра для выгрузки.

## 0.2.0

- Добавлена пробная выгрузка CSV по наименованию или коду ТН ВЭД.
- За один запуск выгружаются до двух страниц с указанием общего размера выдачи.

## 0.1.1

- Добавлен официальный промежуточный сертификат GlobalSign для проверки цепочки TLS реестра. Проверка имени сайта и доверенного корня сохраняется.

## 0.1.0

- Добавлена ручная проверка соединения с реестром Госстандарта и скачивание полученного HTML.
