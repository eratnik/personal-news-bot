# Domis Registry

Проверяет доступ к реестру Госстандарта из контейнера Home Assistant.

1. Запустите приложение и откройте его веб-интерфейс.
2. Нажмите **Проверить соединение**.
3. Если сайт ответил, скачайте HTML по ссылке под результатом. Ошибка соединения также выводится в журнале приложения.

Версия 0.1.0 сохраняет исходный HTML для анализа. Выгрузка записей по товарным группам и расписание потребуют проверки структуры сайта.
