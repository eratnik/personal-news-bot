# Domis Registry

Проверяет доступ к реестру Госстандарта из контейнера Home Assistant.

1. Запустите приложение и откройте его веб-интерфейс.
2. Нажмите **Проверить соединение**.
3. Если сайт ответил, скачайте HTML по ссылке под результатом. Ошибка соединения также выводится в журнале приложения.

Для пробной выгрузки выберите **Наименование** или **Код ТН ВЭД**, введите значение и нажмите **Выгрузить CSV**. Скачайте результат по ссылке **Скачать CSV последней успешной выгрузки**. Один запуск читает до двух страниц. Интерфейс показывает число выгруженных записей и общий размер выдачи. При ошибке сохраняется предыдущий успешный CSV.

Выгрузка запускается вручную.
