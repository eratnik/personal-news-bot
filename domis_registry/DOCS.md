# Domis Registry

Проверяет доступ к реестру Госстандарта из контейнера Home Assistant.

1. Запустите приложение и откройте его веб-интерфейс.
2. Нажмите **Проверить соединение**.
3. Если сайт ответил, скачайте HTML по ссылке под результатом. Ошибка соединения также выводится в журнале приложения.

Для пробной выгрузки выберите **Наименование** или **Код ТН ВЭД**, введите значение и нажмите **Выгрузить CSV**. Скачайте результат по ссылке **Скачать CSV последней успешной выгрузки**. Один запуск читает до двух страниц. Интерфейс показывает число выгруженных записей и общий размер выдачи. При ошибке сохраняется предыдущий успешный CSV.

В разделе **Настройка сохранённых фильтров** можно добавить ключевые слова, фразы и коды ТН ВЭД. Вводите по одному значению на строку и нажмите **Сохранить фильтры**. По умолчанию есть несколько категорий бытовой техники из каталога domis.by. Список кодов пуст, пока вы не добавите свои коды.

Нажмите **Выгрузить все фильтры**, чтобы последовательно проверить все сохранённые ключевые слова и коды ТН ВЭД. Общая выгрузка выполняется в фоне и читает все страницы выдачи. Пока она идёт, панель обновляет статус каждые три секунды. После завершения скачайте общий CSV. Записи с одинаковым номером объединяются. При ошибке в панели появится её причина, а предыдущий общий файл сохранится.

Для пробы по одному фильтру выберите его в списке или откройте **Разовый поиск**.
