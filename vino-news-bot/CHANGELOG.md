# Журнал изменений

## 0.5.1

- Исправлена обработка ответа VK API при получении названия сообщества: приложение больше не завершает работу из-за изменения формата ответа.

## 0.5.0

- Для новостей с сайтов бот извлекает основную картинку из статьи и прикрепляет её к уведомлению Telegram.
- Если у статьи нет изображения или Telegram не может его загрузить, уведомление отправляется в текстовом виде.

## 0.4.0

- VK-уведомления теперь показывают название сообщества, прикреплённую фотографию и ссылку «Подробнее».
- Убрано дублирование текста публикации.

## 0.3.3

- Добавлена иконка приложения для Home Assistant.

## 0.3.2

- Исправлено распознавание ссылок формата `vk.com/club…` и `vk.com/public…`.
- Добавлено разрешение коротких адресов групп, включая `m.vk.ru/mastersland`.

## 0.3.1

- Исправлено отображение журнала изменений в Home Assistant.

## 0.3.0

- VK-группы теперь добавляются полными ссылками в `vk_group_urls`, как и сайты в `source_urls`.
- Добавлена проверка и удаление повторяющихся VK-источников.

## 0.2.0

- Добавлено получение новых авторских записей из публичных групп VK через сервисный ключ.
- Добавлена исходная группа `club4412744`.

## 0.1.2

- Добавлен специализированный разбор статической главной страницы VinoItaliano.

## 0.1.1

- Добавлен HTTP-запасной вариант для сайтов с устаревшим TLS.

## 0.1.0

- Первый релиз: RSS и извлечение новых статей с сайтов, отправка в Telegram.
