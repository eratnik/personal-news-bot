# Vino News Bot

Приложение проверяет новые публикации источников и отправляет их в Telegram.

## Первичная настройка

1. Создайте бота через `@BotFather` командой `/newbot`.
2. Вставьте полученный токен в `telegram_token` в настройках приложения.
3. Запустите приложение и отправьте боту `/start`.
4. Откройте журнал приложения: там появится ваш `chat_id`.
5. Внесите этот номер в `recipient_chat_ids`, сохраните и перезапустите приложение.

Токен не следует добавлять в GitHub или пересылать в чат.

## Источники

Добавляйте адреса главных страниц или прямые RSS-ленты в `source_urls`. Сначала приложение пытается найти RSS на указанном адресе, а также по путям `/feed/`, `/rss/` и `/atom/`. Если ленты нет, оно извлекает ссылки на статьи со страницы.

Первое сканирование только запоминает уже существующие публикации. Чтобы прислать их сразу, включите `send_existing_on_first_run`.

## Обновления

После обновления версии в этом репозитории Home Assistant предложит обновить приложение в его карточке.


## ВКонтакте

В `vk_service_token` укажите сервисный ключ доступа VK. Добавляйте адреса групп в `vk_group_urls`, например `https://vk.com/club4412744`. Поле `vk_group_ids` оставлено только для совместимости со старыми настройками. Приложение читает только новые авторские записи, пропускает закреплённые и отправляет ссылку на оригинальный пост.
