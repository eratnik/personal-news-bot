# История изменений

## 0.1.6

- После добавления по ID и из поиска показывается результат со ссылкой на карточку товара.
- Повторное добавление сообщает, что товар уже отслеживается, и сохраняет его название, цель и комментарий.

## 0.1.5

- Целевая закупочная цена и ранний сигнал по предложениям в наличии. Допуск по умолчанию 5% выше цели.
- Минимальная закупочная цена у поставщиков с подтверждённым остатком за последние 90 дней сохранённой истории.
- Редактируемый комментарий к позиции и отдельная колонка автоматического сигнала.

## 0.1.4

- Закупочные цены ShopManager отображаются без ручной разметки каждого прайса. Прайсы парсеров исключаются, остальные источники можно отключить вручную.
- Цена без подтверждённого остатка помечается в списке и не используется для рекомендаций.
- Однозначное совпадение полного кода модели подставляет цену из CSV конкурентов. Ручная привязка имеет приоритет.

## 0.1.3

- Настройка ссылок на CSV конкурентов и каталог названий прямо в веб-интерфейсе.
- Отображение названия по точному ID из ShopManager или отдельного JSON/YML-каталога. Ручной ввод для товаров без названия в каталоге.
- Кнопка «Добавить к отслеживанию» в результатах поиска и в карточке ещё не отслеживаемого товара. Поиск по каталогу, списку наблюдения и истории точного ID.

## 0.1.2

- Отдельный CSV как единственный источник цен конкурентов.
- Привязка моделей, история цен по магазинам и сравнение с минимальной актуальной ценой.

## 0.1.1

- Быстрое добавление из поиска и по ID.
- Редактирование названия и закупочного лимита в карточке товара.

## 0.1.0

- Первое приложение Home Assistant со списком наблюдения, историей цен ShopManager в SQLite и сводками в Telegram или по почте.
