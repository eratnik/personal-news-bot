# Монитор закупок

В конфигурации Home Assistant задайте URL выгрузки ShopManager в `feed_url`. В веб-интерфейсе приложения откройте «Источники данных» и укажите HTTPS-ссылку на CSV конкурентов. CSV содержит колонку `title` и отдельную колонку для каждого магазина. Поддерживаются UTF-8 и Windows-1251.

Если ShopManager выгружает только ID, в том же разделе можно подключить каталог названий. Поддерживается JSON-массив товаров или объект с массивом `products`. Для каждой позиции укажите `id` и `name` или `title`. В YML используются `offer id` и `name` или `model`. ID должны совпадать с ID ShopManager.

Отметьте оптовые прайсы ShopManager как поставщиков. Добавьте товар по ID или из результатов поиска. Если название найдено в каталоге, достаточно ID. Для остальных позиций введите название при добавлении. В карточке можно изменить название, задать закупочный лимит и привязать модель из CSV.

По умолчанию цены проверяются каждые 6 часов, история сохраняется в SQLite, а сводка формируется раз в 3 дня. Для доставки настройте Telegram или SMTP в конфигурации Home Assistant.

## Доступ для коллег

Настройте отдельный HTTPS-адрес в KeenDNS или другом обратном прокси. В конфигурации приложения задайте `editor_proxy_ip` равным IPv4-адресу, с которого прокси соединяется с приложением, и добавьте в `editor_accounts` отдельные пары `username` и `password`. Для каждого сотрудника используйте уникальный логин и случайный пароль длиной от 15 символов. Удаление записи и перезапуск отзывают доступ.

В разделе сети приложения включите порт `8100/tcp` и направьте HTTPS-прокси на этот порт по локальной сети. Вход выполняется через форму приложения по HTTPS, выход — кнопкой «Выйти». Прокси должен пропускать cookies и параметры запроса. Используйте доверенный сегмент сети между прокси и приложением. Публикуйте только адрес HTTPS-прокси. Прямой проброс порта 8100 из интернета не нужен. Проверьте вход с внешней сети и убедитесь, что для редактора отсутствуют настройки источников.

Коллеги используют отдельные логины приложения. Они могут добавлять и убирать товары из общего списка, менять название, цель, комментарий и привязку модели. Текущие цены и история общие. Администратор управляет источниками и уведомлениями через Home Assistant.
