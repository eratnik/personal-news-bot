# Монитор закупок

Приложение для Home Assistant OS. Список наблюдения, история предложений и состояние расписания хранятся в SQLite по пути `/data/prices.sqlite3`. Интерфейс открывается через Ingress после входа в Home Assistant.

## Запуск

Установите приложение из магазина Home Assistant. В конфигурации заполните `feed_url` полной HTTPS-ссылкой на выгрузку. Для уведомлений заполните `telegram_token` и `telegram_chat` либо настройки SMTP. Запустите приложение, назначьте роли источникам и добавьте интересующие товары по ID или кнопкой «Добавить» рядом с результатом поиска. Название и закупочный лимит можно заполнить позже в карточке товара.

По умолчанию приложение проверяет выгрузку раз в 6 часов и хранит снимки 90 дней. Сводка формируется раз в 3 дня при наличии подходящих позиций. Кандидатом считается товар с доступным закупочным предложением в пределах заданного лимита или минимум на 15% дешевле самой низкой доступной цены отмеченных конкурентов. Сравнение ориентировочное и использует цены из выгрузки.

Поддерживается один настроенный адрес за раз. JSON ShopManager использует `products`, `extraPrices`, `prices`, закупочную цену `origPriceWRate` и остаток `stock`. В качестве текущего состояния используется последний снимок. Поддерживаются также YAML той же структуры и YML XML с `offers/offer`. Для однородного YML укажите роль источника до первого запуска. Для сравнений между независимыми выгрузками потребуется сопоставление идентификаторов и одновременный импорт нескольких адресов.
