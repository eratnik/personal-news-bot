# Монитор закупок

В конфигурации Home Assistant укажите HTTPS-адрес ShopManager в `feed_url` и HTTPS-адрес CSV конкурентов в `competitor_url`. Приложение читает конкурентные цены только из CSV с разделителем «;», колонкой `title` и отдельной колонкой для каждого магазина. Поддерживаются UTF-8 и Windows-1251. Оба источника используют одну валюту, по умолчанию BYN.

Отметьте оптовые прайсы ShopManager как поставщиков. Добавьте товар по ID или кнопкой «Добавить» рядом с результатом поиска. В карточке товара можно указать название, закупочный лимит и выбрать точную строку CSV в поле «Модель у конкурентов».

Приложение проверяет источники раз в 6 часов, хранит историю в SQLite и сравнивает закупочную цену с минимальной указанной ценой из CSV. Если CSV не удаётся обновить два интервала подряд, его цены не используются для рекомендаций. Для сводок укажите настройки Telegram или SMTP. Интервал по умолчанию составляет 3 дня.
